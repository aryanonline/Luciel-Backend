# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability reporting: open
this repository's **Security** tab and choose **Report a vulnerability**. Please do not
open a public issue, pull request or discussion about a security problem.

A useful report says what you found, where it is (file, endpoint or workflow) and how to
reproduce it.

## Hosted environment

The hosted Luciel environment is paused, so there is no live service to test. Reports
about the code, the infrastructure templates and the workflows in this repository are
still welcome. Do not test against systems you do not own.
